# todo-list

Miniproyecto Lista de tareas pendientes

Este miniproyecto fue creado para aprender a trabajar con git y github, ademas del uso de ramas y commits pequenos que marquen un avance en el proyecto. Tambien se pratico el uso de LocalStorage.

Funcionalidades implementadas:
Agregar una tarea nueva.
Eliminar una tarea existente.
Marcar una tarea como completada.

El proyecto se ejecuta de manear nativa al no poder conectar con GitHub Pages.
En el cuadro de texto se escribe la tarea a realizar, cuando se cliquea el boton "Agregar" la tarea se muestra en pantalla. A esa tarea se le puede hacer dos cosas; El boton "ELIMINAR" elimina la tarea y la casilla marca la tarea como completada. Se muestra un mensaje en pantalla cuando el usuario agrega o elimina una tarea, ademas de mostrar uno en caso de que el usuario intente agregar una tarea sin contenido.

Las tecnologias usadas fueron HTML para podes visualizar el proyecto, CSS para darle estilo a la pagina, JavaScript para darle funcion a cada elemento del proyecto y LocalStorage para guardar los datos en el navegador.
